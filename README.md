# 🚤 Yacht Website

A modern luxury yacht showcase website built with a premium 3D-inspired user experience, smooth animations, and immersive UI design. This project focuses on creating a visually stunning and interactive web experience that gives users a high-end luxury feel while exploring yachts online.

---

## 🌊 Overview

This project was created to explore modern frontend development, creative UI/UX concepts, and AI-assisted workflows for building visually engaging websites.

The website includes:

* Modern luxury-inspired design
* Smooth scrolling and animations
* Interactive sections
* Responsive layout
* 3D visual experience
* Premium aesthetic inspired by luxury yacht brands

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/your-username/yachtwebsite.git
```

### Navigate into the project

```bash
cd yachtwebsite
```

### Install dependencies

```bash
npm install
```

### Run the development server

```bash
npm run dev
```
